# GAC Counter Planner

- **Demo report:** https://nrbarnard83.github.io/gac-demo/
- **Set it up (bookmark button and steps):** https://nrbarnard83.github.io/gac-demo/planner/

A browser-only planner for Grand Arena: predicts an opponent's defense, picks counters that clear a safe win-rate bound, and builds your own defense from the units left over. It runs in your own signed-in swgoh.gg tab (GAC Insight access required) and uploads nothing. This repo holds only the static page and one script.
